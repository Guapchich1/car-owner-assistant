# Помощник автовладельца

## О проекте
Веб-приложение для автовладельца:
- карточка машины по VIN (пользователь подтверждает характеристики);
- журнал работ и расходов;
- план ТО по регламенту модели и пробегу;
- ссылки на поиск запчастей и автосервисов;
- ИИ-помощник, который отвечает на вопросы со ссылками на источники.

Машины российского рынка. Код пишет ИИ-агент, команда проверяет.

## Стек
- Python 3.12, FastAPI, шаблоны Jinja2, HTMX, Pico.css
- SQLite + SQLAlchemy 2.0, миграции Alembic
- Настройки и ключи в .env
- pytest для тестов, ruff для проверки кода

## Структура
- app/main.py — запуск приложения
- app/routers/ — страницы
- app/models.py — таблицы БД
- app/services/ — логика (VIN, план ТО, LLM)
- app/templates/ — HTML-шаблоны
- app/data/ — справочники в JSON
- tests/ — тесты
- docs/ — документация

## VIN
- Определяем что можем из самого VIN: марку, страну, год, иногда модель.
- Для импортных машин — запасной вариант NHTSA vPIC.
- Остальное пользователь выбирает из справочника: марка → модель → двигатель.
- В справочнике популярные модели российского рынка с регламентом ТО.

## ИИ-помощник
- Модель: YandexGPT Lite через библиотеку openai.
- Вся работа с LLM — только в app/services/llm.py.
- Ищем подходящие тексты в своей базе (SQLite FTS5), передаём их модели,
  ответ содержит ссылки на источники.
- В тестах настоящую LLM не вызываем, используем заглушку.

## Правила
- Перед «готово» запусти `pytest` и `ruff check .` — всё должно проходить.
- Новая функция — новый тест.
- Работай в ветке `feature/<имя>`, в main не коммить.
- Одна задача — одна ветка — один PR.
- Не трогай .env.
- Новые библиотеки и изменения структуры — только после согласования.
- Комментарии, интерфейс и коммиты — на русском.
- Если что-то неясно — спроси.
