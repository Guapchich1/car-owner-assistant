# Журнал работы с ИИ-агентом

Одна запись — одна сессия с агентом. Новые записи добавляем сверху.

## Шаблон записи

### ГГГГ-ММ-ДД — дата и краткое название задачи
- **Кто:** имя того, кто давал задачу
- **Задача:** ссылка на issue, где написано, что требовалось
- **Что попросили:** основной промпт своими словами
- **Что сделал агент:** 
- **Что пришлось исправлять:** 
- **Вывод:** 
- **PR:** ссылка
