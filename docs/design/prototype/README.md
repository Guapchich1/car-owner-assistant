# АвтоГид AI — расширенная сервисная книжка

Основным выбран дизайн № 7: светлая зелёная палитра, карточка автомобиля, история обслуживания и план ТО. Это самостоятельный интерактивный прототип на HTML/CSS/JavaScript, без установки пакетов и внешних CDN.

## Запуск

Распакуйте **весь архив** и откройте `index.html`. Для стабильного локального адреса можно запустить из этой папки `python3 -m http.server 8000` и открыть приложение на порту 8000 в браузере.

Изменения хранятся в `localStorage` этого браузера и адреса сайта. Другой браузер, устройство или адрес не получат их автоматически. Если браузер запрещает локальное сохранение, интерфейс покажет предупреждение; экспорт позволяет сохранить историю в файл.

## Добавленные возможности

- **Журнал работ:** добавление, редактирование, удаление с подтверждением, поиск по работе/сервису/примечанию, фильтры по категории и году.
- **Загрузка истории:** CSV и JSON, предварительный просмотр, проверка полей и пропуск совпадающих записей. Файл обрабатывается локально. При ошибке ни одна запись из файла не добавляется.
- **Экспорт:** JSON для переноса истории без изменений и CSV для таблиц. Примеры файлов находятся в `samples/`.
- **План ТО:** интервал замены масла настраивается вручную; следующая замена рассчитывается от последней записи с категорией «Масло и фильтр». Выполненную работу можно добавить в журнал из плана. Остальные проверки показывают демонстрационные сроки.
- **Расходы:** суммы за месяц и за всё время, распределение по категориям работ. Топливо и страховка в эти суммы не входят.
- **Тюнинг и улучшения:** шумоизоляция, CarPlay / Android Auto, камера, видеорегистратор, шины, консультация по настройке ЭБУ. Избранные идеи сохраняются, диапазоны примерного бюджета суммируются. Это не подтверждённая совместимость и не предложения сервисов.
- **Документы:** редактируемые даты окончания ОСАГО, водительского удостоверения и диагностической карты. Номера демонстрационные, копии документов не загружаются. Напоминания показываются внутри приложения, без push/email.
- **Карточка авто:** пробег и VIN как локальная заметка. Модель остаётся демонстрационной Škoda Octavia; декодирование VIN не подключено.
- **Поиск по приложению:** разделы, работы и сервисы. Помощник содержит переходы к нужным разделам и явно сообщает, что LLM не подключена.

## Формат истории

CSV использует `;` или `,` как разделитель. Поддерживаются кавычки, разделители и переносы строки внутри кавычек. Обязательные колонки: `date`, `mileage`, `title`, `amount`. Необязательные: `type`, `service`, `note`.

JSON принимает массив записей либо объект с массивом `records`.

- `date`: настоящая календарная дата в формате `ГГГГ-ММ-ДД`.
- `mileage`: целое число от 0 до 3 000 000 км.
- `amount`: число от 0 до 100 000 000 рублей, до двух знаков после запятой.
- `type`: `oil`, `filters`, `brakes`, `tires`, `diagnostic`, `other`; при отсутствии — `other`.
- `title`: 1–180 символов; `service`: до 120; `note`: до 2000.

Лимиты: до 2 МБ на импорт и до 2000 записей в истории. Совпадение даты, пробега, категории, названия без учёта регистра и суммы считается дубликатом, независимо от названия сервиса и примечания. VIN, документы и список тюнинга не включаются в экспорт истории. CSV нейтрализует значения, начинающиеся с символов формул; для точного переноса предпочтителен JSON.

## Проверка

В Chromium проверены добавление, редактирование, удаление и сохранение после перезагрузки; фильтры; CSV с разделителями и переносами внутри кавычек; предварительный просмотр; пропуск дублей; отказ от некорректной даты без изменения истории; экспорт JSON и обратный импорт; сохранение выбранного тюнинга; изменение документов и пересчёт плана после замены масла. Проверены все шесть разделов при ширине экрана 390 пикселей. Скриншоты — в `screenshots/`.

Это развитие дизайна и локального интерфейса. Python, SQLite, SQLAlchemy, VIN API, внешняя история автомобиля и LLM API пока не подключены. Новые браузеры начинают с синтетических примеров; загрузка реальной истории требует файла пользователя.
